# Security policy

## Reporting a vulnerability

Please report suspected security issues privately rather than publishing
working exploit details. Use GitHub's private vulnerability reporting feature
if it is enabled for this repository. Otherwise, contact the repository owner
through GitHub and request a private reporting channel.

Please include the affected version, operating system, steps to reproduce, and
the impact you observed. Do not include API keys, private conversations, or
other user data in a report.

## Supported versions

Security fixes are intended for the latest supported release. This policy will
be updated as additional release branches are maintained.
